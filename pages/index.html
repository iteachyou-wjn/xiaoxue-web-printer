晓雪WEB打印控件让浏览器真正打得出、打得准

基于本机打印服务 + WebSocket 的 Web 打印控件。text / HTML 一键渲染成 PDF 真实打印，支持打印预览、任务管理、BarTender 模板打印，天然适配 Vue / React / Angular 等主流前端框架。

在线 Demo

真实打印，稳定可靠

不依赖浏览器原生打印对话框。本机打印服务将 text / HTML 渲染为 PDF 后通过系统打印服务输出，精准控制纸张、方向、页边距、页眉页脚与缩放。

所见即所得的打印预览

doPreview 弹出分页预览窗口，支持缩放、翻页、页面设置、导出 PDF 与图片，打印前可充分检查版式。

简单易用的 SDK

一行引入，两行调用。Promise 化 API：连接管理、打印机/纸张查询、打印、预览、任务管理一应俱全，浏览器与 Node.js 均可使用。

主流框架开箱即用

提供 Vue 2 / Vue 3 / React / Angular 完整集成示例，覆盖 CDN 单页与工程化项目两种接入方式。

BarTender 模板打印

深度集成 BarTender 标签软件，支持模板参数读取、模板图像预览与带参数打印，适配条码、标签、证卡等专业打印场景。

安全可控的本机服务

仅监听 127.0.0.1 回环地址，不对外开放端口；系统托盘驻留、任务队列可视化管理，支持授权许可与开机自启。
