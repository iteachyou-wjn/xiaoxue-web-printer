技术架构 ​

晓雪WEB打印控件整体分为本机打印服务（Java 后端）与 前端 SDK（浏览器）两部分，中间通过 WebSocket 通信。

打印链路 ​

doPrint 与预览窗口中的"打印"共用同一链路：

  1. 组装文档：HtmlRenderService 将 text / HTML 与 style 编成 XHTML，通过 @page 设置纸张、边距、页眉页脚，图片内嵌为 base64；
  2. 渲染 PDF：OpenHTMLtoPDF 渲染为 PDF（Windows 注册的宋体 / 微软雅黑等字体自动匹配）；
  3. 输出打印：PrintTaskExecutor 使用 PDFBox PDFPageable + PrinterJob 输出到指定打印机。

通信协议概要 ​

WebSocket 消息为 JSON 文本。请求按 type 区分，响应使用 type_result / type 形式：

请求 type响应 type说明
doPrintdoPrint_result提交并执行打印任务
doPreviewdoPreview_result打开打印预览窗口
printersprinters_result本机打印机列表
pageSizepageSize_result指定打印机的纸张列表
listtask_list打印任务列表
statustask_status单个任务状态
cancelcancel_result取消任务
clearclear_result清除已完成/失败任务
bartenderInstancebartenderInstance_resultBarTender 实例与版本
bartenderTemplateParamsbartenderTemplateParams_result模板参数
bartenderTemplateImagebartenderTemplateImage_result模板图像（base64）
bartenderTemplateImageWithParamsbartenderTemplateImageWithParams_result带参数模板图像

服务端还会主动推送：

  • welcome：连接建立后的欢迎消息（含端口等）；
  • task_list_update：任务状态变化时推送最新任务列表。

详细字段与完整示例见 WebSocket 协议 与 SDK 类参考。
